# CWaypoint

An AI-assisted, interactive learning app for C and C++, built with C/C++ and raylib.

Small steps. Strong foundations.

## Status

Initial repository setup. Application implementation and build configuration are not yet added.

## First learning core

The first C variables lesson and evaluator are available as a standalone C++17 handoff. Run `make test` to verify grading and compile-check the C example. Run `make demo` for a terminal demonstration. See [integration notes](docs/integration.md) and [Friday record](docs/friday-2026-11-06.md).
